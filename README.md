# FIELDWISE AI
### NASA-Powered Smart Crop Rotation & Climate Resilience System

FIELDWISE AI is an agricultural decision-support platform that helps farmers plan sustainable, climate-resilient crop rotations using NASA Earth observation data.

## Key Features

- Three-season crop rotation recommendations
- NASA POWER climate data and GPM/IMERG rainfall integration
- 30-year historical climate replay
- Drought, heat and heavy-rainfall simulations
- Water efficiency and soil compatibility analysis
- Interactive visualizations and explainable recommendations
- Downloadable Farmer Cards

## Tech Stack

- **Backend:** Python, Flask, Pandas
- **Frontend:** HTML, CSS, JavaScript, Chart.js, Leaflet
- **NASA Data:** POWER and GPM/IMERG
- **Testing:** Pytest


## Our Mission

To transform NASA satellite and climate data into accessible agricultural insights, helping farmers improve water efficiency, manage climate risks, and make informed multi-season crop planning decisions.

## Disclaimer

FIELDWISE provides model-based agricultural decision support, not guaranteed crop yields or weather forecasts. GPM rainfall observations depend on data availability, and mock demonstrations are explicitly labelled.
